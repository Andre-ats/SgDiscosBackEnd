# SGDiscosBackEnd

Backend do sistema **SGDiscos**, uma plataforma de e-commerce focada na venda de discos de vinil.

O sistema permite que usuários criem contas, naveguem pelo catálogo de vinis e realizem compras diretamente pelo site. Além disso, conta com um **painel administrativo**, onde administradores podem cadastrar novos discos, acompanhar vendas e visualizar estatísticas do sistema.

## 🚀 Tecnologias

* C#
* ASP.NET
* Entity Framework
* PostgreSQL

## 📚 Sobre o Projeto

O **SGDiscos** foi desenvolvido para oferecer uma experiência completa de compra de discos de vinil online.

A plataforma possui dois principais fluxos de uso:

**Usuário**

* Criar conta
* Realizar login
* Navegar pelo catálogo de vinis
* Comprar discos disponíveis na plataforma

**Administrador**

* Cadastrar novos vinis
* Gerenciar catálogo
* Acompanhar vendas
* Visualizar estatísticas e dados do sistema

A aplicação está atualmente **em desenvolvimento** e novas funcionalidades continuam sendo adicionadas.

## 🗄️ Banco de Dados

O sistema utiliza **PostgreSQL** como banco de dados principal, com **Entity Framework** para mapeamento objeto-relacional (ORM).
